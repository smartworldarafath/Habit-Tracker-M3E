## 🚀 What's New in v1.3.0

### <img src="https://upload.wikimedia.org/wikipedia/commons/c/c9/Finder_Icon_macOS_Big_Sur.png?utm_source=commons.wikimedia.org&utm_campaign=index&utm_content=original" width="22" height="22" valign="middle" alt="macOS" /> macOS Desktop Release (Apple Silicon & Intel)
- **Native DMG Installer & Portable ZIP:** Built and packaged natively for Apple Silicon (M1/M2/M3/M4) and Intel Macs (`macOS 12.0+ Monterey and newer`).
- **Drag-and-Drop Installation:** Standard `.dmg` installer with drag-to-Applications flow, plus standalone portable `.zip` archive.
- **Mac Experience:** Keyboard navigation, native window resizing, dark/light theme integration, and high-DPI Retina rendering.

### <img src="https://static.vecteezy.com/system/resources/thumbnails/021/496/368/small/ios-icon-logo-software-phone-apple-symbol-with-name-black-design-mobile-illustration-free-vector.jpg" width="22" height="22" valign="middle" alt="iOS" /> iOS Universal Release (iPhone & iPad)
- **Universal IPA Package:** Built natively for both **iPhone** and **iPad** (iOS 15.0+ / iPadOS 15.0+).
- **Easy Sideloading:** Install seamlessly using [**AltStore**](https://altstore.io), [**Sideloadly**](https://sideloadly.io), [**TrollStore**](https://github.com/opa334/TrollStore), or [**Scarlet**](https://usescarlet.com).
- **iPad Optimized:** Full support for landscape, portrait, and split-screen multitasking.

### <img src="https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcTOxYL1ESXVU3dbGhhKUf6YqL2WmXGdPWC2GomXKeBJF40CE2YRMvKptE91&s=10" width="22" height="22" valign="middle" alt="Windows" /> Windows & <img src="https://cdn-icons-png.flaticon.com/512/6124/6124995.png" width="22" height="22" valign="middle" alt="Linux" /> Linux Desktop Releases
- **Windows Setup Wizard & Portable ZIP:** Native x64 Windows installer with desktop shortcuts, Start Menu entry, clean uninstaller, and portable ZIP.
- **Linux AppImage & Tarball:** Complete Linux x64 support packaged as standalone AppImage (just `chmod +x` and run) and portable tarball, tested across Ubuntu, Debian, Fedora, and Arch.
- **Desktop UI Optimization:** Fluid keyboard navigation, window sizing, and responsive layout for widescreen monitors.

### <img src="https://uxwing.com/wp-content/themes/uxwing/download/brands-and-social-media/android-icon.png" width="22" height="22" valign="middle" alt="Android" /> Android Enhancements
- **120Hz & 144Hz Native High Refresh Rate:** Automatically engages full 120Hz/144Hz display modes across phones and tablets (including Xiaomi Pad 7, 7 Pro, 8, 8 Pro, OnePlus, Samsung Galaxy, and Pixel).
- **Predictive Back Navigation:** Enabled `android:enableOnBackInvokedCallback="true"` with interactive swipe-to-pop gestures and smooth deceleration transitions.

### ☀️ Pure Light Mode Fix
- **Pristine Backgrounds:** Resolved an issue where backgrounds stayed dark in light mode across Today, To-do, Plan, Stats, and Settings tabs. Surfaces and custom wallpapers now shine through with complete clarity.
- **Accurate System Theme Tracking:** Theme brightness and status bar overlays dynamically synchronize with chosen appearance options.

### 🖼️ Profile Avatar Hero Transition & Edit Action
- **Shared Element Floating Preview:** Tapping the profile picture in Settings triggers a smooth Hero transition enlarging the avatar floating over a frosted blurred backdrop.
- **Quick Edit Pencil Action:** Dedicated floating pencil icon button next to the enlarged avatar to quickly update or pick a new profile photo.

### 🏷️ Complete Brand Polish ('M3E')
- **Settings Footers & App Branding:** Updated Settings bottom version footer to `M3E v1.3.0` and refined app headers, notification channels, onboarding title, and share cards to `M3E` / `Habit Tracker M3E`.
- **Package Integrity:** Verified package identifier as `com.habittrackerm3e.app`.
